## PROJECT DESCRIPTION

The Automated Backup System is a Bash-based
Linux automation project designed to create,
verify, restore, and manage backup archives.

The system uses TAR and GZIP for compression,
SHA-256 for data integrity verification, and
Cron for scheduled backup operations.

---

## KEY COMPONENTS

1. Backup Module

   * Creates compressed backup archives.
   * Generates unique timestamp-based filenames.
   * Stores backups in the designated archive directory.

2. Integrity Verification

   * Generates SHA-256 checksums.
   * Verifies backup integrity before restoration.

3. Restore Module

   * Extracts backup archives.
   * Restores files to a specified directory.

4. Cleanup Module

   * Identifies expired backup files.
   * Removes backups according to the retention policy.

5. Logging Module

   * Records backup and cleanup activities.
   * Maintains operational information for troubleshooting.

6. Automation Module

   * Uses Cron to schedule recurring backup operations.
